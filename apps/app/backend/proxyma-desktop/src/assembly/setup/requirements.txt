# download the wheels, and by ProxymaLauncher.ensurePython to install them offline.
#
# Changing this file changes the python part, which every install then downloads again and
# rebuilds its Python runtime from - see tools/release/parts.py.

# get-pip.py installs it from these wheels (ProxymaLauncher.installPip) rather than from PyPI, which
# a rebuild offline or behind a proxy that blocks PyPI cannot reach.

chromadb
